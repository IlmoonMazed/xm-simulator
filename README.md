# XM Simulator

A lightweight, browser-based exam simulator designed to help students practice timed MCQ exams, track their progress, and analyze their performance.

Built with **HTML, CSS, and vanilla JavaScript**. No backend or account required.

## Features

- **Custom Exam Setup** — Configure exam duration, subjects, question counts, number of options, and marking scheme.
- **Flexible Answering** — Support for single-answer and multiple-answer questions.
- **Checkpoint Tracking** — Record progress at custom time intervals, including answered questions and answer changes.
- **Timed Exams** — Automatic submission when the timer expires.
- **Performance Analysis** — Review correct, incorrect, and unanswered questions.
- **Detailed Reports** — Analyze performance by subject, question, answer option, and checkpoint.
- **Answer Change History** — Track when and how answers were changed.
- **PDF Export** — Download detailed exam reports.
- **Local Storage** — Keep exam reports saved in your browser.
- **Light and Dark Themes** — Choose your preferred appearance.

## Getting Started

### Run on Browser

Visit https://ilmoonmazed.github.io/xm-simulator/ to start an xm.

### Run Locally

1. Download or clone this repository.
2. Make sure these files are in the same directory:
   - `index.html`
   - `styles.css`
   - `app.js`
3. Open `index.html` in your browser.

No installation or build process is required.

### Run with GitHub Pages

1. Fork or upload this repository to GitHub.
2. Navigate to **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Choose the `main` branch and `/ (root)` folder.
5. Save and wait for deployment.

Your simulator will be available at:

`https://<username>.github.io/<repository-name>/`

## Technology Stack

- HTML5
- CSS3
- JavaScript
- Browser Local Storage
- jsPDF (for PDF report generation)

## Data & Privacy

- Exam data and saved reports are stored locally in the browser.
- No user account or backend server is required.
- Data is not automatically synchronized across devices or browsers.
- Clearing browser storage may permanently remove saved reports.
